Privacy Policy

This section explains how MCSync handles information used to synchronize Discord roles with Minecraft and Hytale server access.

1. Data We Handle

  • Discord user data: username and server roles.
  • Game account data: Minecraft or Hytale username and UUID.
  • Discord server data: server name, server ID, and role information.

MCSync does not collect message content, payment data, email inbox content, or DM history as part of normal operation.

2. How We Use Data

  • Validate linked identity and role eligibility.
  • Grant or revoke game-server access based on Discord roles.
  • Operate setup, mapping, and sync reliability workflows.
  • Troubleshoot operational issues and maintain service integrity.

3. Sharing, Retention, and Security

We do not sell personal data. Data is used only for service operation and required platform integrations. Data is retained only as needed for operations and legal requirements. We apply reasonable safeguards, but no system can guarantee absolute security.

Data Collection Policy

This section lists exactly what MCSync collects and why.

1. Data Categories Collected

  • Discord username.
  • Discord user roles inside the server.
  • Minecraft username and UUID.
  • Hytale username and UUID.
  • Discord server name and server ID.
  • Discord server role definitions and role mappings used for synchronization.

2. Collection Sources

  • User-provided values during account linking and setup commands.
  • Discord API data available through granted bot permissions.
  • Role-sync operations generated from your server configuration.

3. Purpose and Minimization

Data is collected only for role synchronization, identity linking, and access control to connected game servers. MCSync is designed to avoid collecting unrelated personal content.

4. Retention and Policy Updates

Collected data is retained only while operationally necessary or legally required. This policy may be updated when service behavior or requirements change.

5. Data Subject Requests

You may request access, correction, deletion, or additional information about collected data by contacting opt-out@mcsync.live. Requests are handled subject to identity verification, operational necessity, and legal retention obligations.
